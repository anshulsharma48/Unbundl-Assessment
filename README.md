

A responsive landing page based on the Clove Dental Figma design, built using HTML, CSS, and Vanilla JavaScript.

## 6 Selected Sections (from Figma)
1. **Hero Section (with Consultation Form)**: Headline ("Painless Root Canal Treatment in Delhi"), doctor info, and booking form with captcha.
2. **Stats Ribbon**: Quick numbers highlighting clinics (600+), dentists (1300+), and patients.
3. **Types of Root Canal Treatments**: Comparison cards for standard RCT vs. Re-RCT with pricing and consultation CTA.
4. **Why Choose Clove Dental**: Expandable accordion detailing clinic features (AI chair, sterilization, specialists) paired with doctor photo.
5. **Find Us Across India**: Clinic network card grid showing clinic counts across Delhi/NCR, Bangalore, Mumbai, Chennai, Hyderabad, and Pune.
6. **Frequently Asked Questions (FAQ)**: Patient questions accordion.

(Includes standard Navbar with logo & phone contact and Footer with copyright links).

## Tech Stack
 HTML5 (Semantic structure)
 CSS3 (Flexbox, CSS Grid, media queries for responsiveness)
 Vanilla JavaScript (Form validation, mobile nav toggle, accordions)
